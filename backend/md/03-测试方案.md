## 三、API 测试 (httpx + pytest)

### 测试场景

| 接口 | 正常场景 | 异常场景 | 边界场景 |
|------|---------|---------|---------|
| 上传图片 | 上传 jpg → 返回 image_id | 上传 txt → 415 | 10.1MB → 413 |
| 发起会话 | 传 image_id → 返回 stream_url | 传空 → 422 | 超长 text → 截断 |
| 流式读取 | 读流 → 正确收到 events | message_id 无效 → 404 | 中途断连 |
| 中断 | 正常中断 → 200 | message_id 无效 → 404 | 已完成的再中断 |

```python
# test_upload.py
def test_upload_success(client, test_image):
    resp = client.post("/api/v1/upload/image", files={"file": test_image})
    assert resp.status_code == 200
    assert resp.json()["data"]["image_id"] is not None

def test_upload_too_large(client):
    big_file = io.BytesIO(b"x" * (10 * 1024 * 1024 + 1))
    resp = client.post("/api/v1/upload/image", files={"file": ("big.jpg", big_file, "image/jpeg")})
    assert resp.status_code == 413

def test_upload_invalid_format(client):
    resp = client.post("/api/v1/upload/image", files={"file": ("test.txt", b"hello", "text/plain")})
    assert resp.status_code == 415
```

## 四、压力测试 (Locust)

### 压测目标

| 指标 | 目标值 |
|------|--------|
| 并发用户数 | 500 |
| 平均响应时间 | < 500ms |
| TP99 响应时间 | < 3s |
| 错误率 | < 1% |
| 图片上传吞吐 | > 50 req/s |

### 压测脚本模板 (`tests/locustfile.py`)

```python
from locust import HttpUser, task, between
import io

class AgentUser(HttpUser):
    wait_time = between(1, 3)

    def on_start(self):
        """每个虚拟用户启动时上传一张图片"""
        img = io.BytesIO(b"fake_image_data")
        resp = self.client.post("/api/v1/upload/image", files={"file": ("test.jpg", img, "image/jpeg")})
        self.image_id = resp.json()["data"]["image_id"]

    @task(3)
    def chat(self):
        """发起会话"""
        resp = self.client.post("/api/v1/chat", json={
            "session_id": None,
            "image_id": self.image_id,
            "text": "推荐类似的商品"
        })
        if resp.status_code == 200:
            self.message_id = resp.json()["data"]["message_id"]

    @task(1)
    def stream(self):
        """读取流式回答"""
        if hasattr(self, "message_id"):
            self.client.get(f"/api/v1/chat/stream?message_id={self.message_id}")
```

### 运行命令

```bash
# 安装
pip install locust

# 启动 Web UI
locust -f tests/locustfile.py --host=http://localhost:8000

# 无头模式（CI 用）
locust -f tests/locustfile.py --host=http://localhost:8000 \
  --headless -u 500 -r 50 --run-time 5m --html report.html
```

## 五、容错测试

### 测试矩阵

| 模拟故障 | 预期行为 | 验证方式 |
|---------|---------|---------|
| Redis 挂了 | 回退本地 dict，服务不崩溃 | 停 Redis → 调接口 → 正常返回 |
| Qdrant 挂了 | 降级到模糊搜索 | 停 Qdrant → 调 chat → 返回结果 |
| OSS 连不上 | 返回 UPLOAD_FAILED 错误码 | 断开 OSS → 上传图片 → 收到错误 |
| LLM 超时 | 中断流，推 error 事件 | 设超时 1ms → 调 chat → 收到 error |
| 图片格式异常 | 返回 INVALID_FORMAT | 上传损坏文件 → 415 |

### 容错脚本示例

```bash
#!/bin/bash
# 模拟 Redis 宕机
echo "=== 测试 Redis 宕机 ==="
docker stop redis
curl -X POST http://localhost:8000/api/v1/chat \
  -H "Content-Type: application/json" \
  -d '{"session_id": null, "image_id": "test", "text": "hello"}'
docker start redis
```
