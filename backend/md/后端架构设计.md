# 后端架构设计 — Python + LangChain

## 项目定位

```
Android 拍照 → 后端 → 图片检索 → 候选商品 → 文本检索 → LLM 流式回答
```

---

## 一、技术栈

| 组件 | 选型 | 说明 |
|------|------|------|
| Web 框架 | FastAPI | 异步，原生支持 SSE 流式 |
| LLM 编排 | LangChain | 串联 embedding → 检索 → 生成 → 流式 |
| 向量数据库 | ChromaDB | 轻量级，无需单独部署 |
| 图片 Embedding | CLIP | 图片 ⇄ 文本同一向量空间 |
| LLM | 待定 | OpenAI / DeepSeek / Ollama |
| 运行环境 | Python 3.10+ | |

## 四、API 接口

| 接口 | 方法 | 说明 |
|------|------|------|
| `/v1/upload/image` | POST | 上传图片 → 返回 image_id |
| `/v1/chat` | POST | 发起会话 → 返回 stream_url |
| `/v1/chat/stream` | GET | SSE 流式读取回答 |

### 1. 上传图片

```
POST /v1/upload/image
Content-Type: multipart/form-data
→ { "image_id": "uuid", "url": "/images/uuid.jpg" }
```

### 2. 发起会话

```
POST /v1/chat
Body: { "session_id": "uuid|null", "text": "推荐类似"|null, "image_id": "uuid" }
→ { "message_id": "uuid", "stream_url": "/v1/chat/stream?message_id=uuid" }
```

### 3. 流式读取

```
GET /v1/chat/stream?message_id=uuid

event: candidates
data: {"candidates": [{"sku_id": "001", "score": 0.92, ...}]}

event: delta_text
data: {"text": "推荐这款蓝牙耳机"}

event: citations
data: {"citations": [{"sku_id": "001", "chunk_id": "c1", ...}]}

event: final
data: {"need_clarify": false, "clarify_question": null}
```

## 五、核心编排流程

```
用户上传图片
    ↓
图片存储 → 返回 image_id
    ↓
CLIP 模型 → 图片转 embedding
    ↓
ChromaDB 图片库 → top-3 候选 SKU
    ↓
候选 SKU 查询文本知识库 → citations
    ↓
LangChain 组装 Prompt → LLM 流式生成
    ↓
SSE 推送给 Android（先发卡片，再逐字推文字）
```

## 六、LangChain 核心代码结构

```python
from langchain_core.prompts import ChatPromptTemplate
from langchain_openai import ChatOpenAI

PROMPT = ChatPromptTemplate.from_messages([
    ("system", """你是电商导购助手。
候选商品：{candidates_text}
相关知识：{citations_text}
要求：
- 推荐理由必须引用商品属性
- 信息不足时引导用户澄清
- 输出中文回答"""),
    ("user", "{question}")
])

def build_chain():
    llm = ChatOpenAI(model="gpt-4o", streaming=True)
    return PROMPT | llm

async def generate_stream(candidates, citations, question):
    chain = build_chain()
    async for chunk in chain.astream({
        "candidates_text": str(candidates),
        "citations_text": str(citations),
        "question": question
    }):
        yield f"event: delta_text\ndata: {chunk.content}\n\n"
```
